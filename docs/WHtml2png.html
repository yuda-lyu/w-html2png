WHtml2png

WHtml2png

(async) new WHtml2png(widthopt, heightopt, scaleopt, html, optopt) → {Promise}

Description:

  • 呼叫Chromium轉Html為png圖

    提供兩種瀏覽器使用模式(opt.mode): 'single'為每次呼叫啟動新瀏覽器, 出圖後即關閉釋放, Node行程可自然結束, 適合排程批次; 'alive'為常駐瀏覽器, 第一次呼叫時啟動, 同行程後續呼叫重用故出圖較快, 閒置超過1小時自動關閉, 批次腳本結束前可呼叫WHtml2png.close()主動關閉常駐瀏覽器, 使Node行程可立即退出(close前已開始之呼叫不再重試重啟瀏覽器); 只有瀏覽器層錯誤(無法開頁、瀏覽器斷線)才於重試前重啟常駐瀏覽器, 頁面層錯誤不影響同時進行之其他呼叫

    未指定opt.executablePath時使用套件自帶之免安裝chrome(只支援Windows), 經WHtml2png.ensureBins(即src/ensureBins.mjs)取得檔案組chrome: 首次調用時下載(約200MB, 或自鏡像W_BIN_MIRROR取得)portable.zip之8個分割, 組合、解出portable/App/Chrome-bin/後逐檔以bin/manifest.json之SHA-256與大小校驗, 整組放入快取(預設本套件根目錄之bin-cache/<組識別>/, 與當前工作路徑無關), 之後自快取取得(每行程首次亦校驗, 一檔不符即整組重取); 安裝套件時不下載; 環境變數W_BIN_CACHE、W_BIN_MIRROR、W_BIN_OFFLINE見README〈外部執行檔〉; 取得chrome永不寫入當前工作路徑(僅opt.fdHtml/opt.fdErr之預設為當前工作路徑下之./_convertTemp)

    頁面模板預先載入lodash(全域_)與wsemi(全域w), 皆由本套件相依之本機檔案供應(不需網路), 可於execJsHead、execJsPost使用

    內容皆逐字插入頁面(含$&、$'、$$等字樣): html置於div#pl內; execJsHead與execJsPost以inline之script插入, 內容不得含字面(需要時寫成</script>); stylesHead與scriptsHead之網址置於屬性內, 不得含雙引號; 未給opt.funGetUrl時以setContent載入(about:blank), html內之本機檔案(file://)與相對路徑資源不會載入, 請改用data url或給opt.funGetUrl

    載入後一律等待頁面確實完成才檢查頁面錯誤、執行opt.funPageWait與截圖: 先等load(同步腳本與load事件處理皆已執行), 再等靜止窗(自load與最後一次網路活動起500毫秒內無請求且進行中之請求皆已結束, 以頁面自身之計時器等待, 故load前所設且延遲不超過500毫秒之計時器必已執行); 窗外之非同步工作請用opt.funPageWait等待; 等待上限60秒, 未達成不視為失敗而續往下

 null

輸入單次出圖(每次嘗試)之允許時長毫秒數，有效正數(數字或數字字串)且不超過2147483647，預設null；超過視為該次失敗並依retry重試，訊息開頭為timeout[Nms] in 步驟(步驟如waitPageSettled、funPageWait、context.newPage()、page.goto())，可據以判斷卡在哪一步。逾時後先限時5秒關閉該頁面：關得掉代表瀏覽器仍可回應，屬頁面層問題，不重啟瀏覽器，不牽連並發呼叫；尚無頁面(取得瀏覽器或開頁卡住)或關不掉屬瀏覽器層問題，關閉本呼叫所用之瀏覽器(alive為本呼叫所用之常駐瀏覽器，不論是否再重試，下次呼叫即啟動新瀏覽器；其他使用同一常駐瀏覽器之並發呼叫會失敗，由各自之retry接住)，關閉限時10秒，超過則確認該pid仍為本實例啟動之瀏覽器後樹狀強制結束(pid於啟動時經CDP取得，無法確認者不結束並於訊息註明)；funGetUrl卡住等尚未取用瀏覽器之逾時不動瀏覽器。每次嘗試最長約timeout加25秒(5秒關頁面、10秒關閉瀏覽器、5秒結束指令、5秒確認斷線)，整次呼叫最長約此值乘retry再加5秒乘(retry-1)；計時不含取得套件自帶chrome(ensureBins有其自身逾時)與重試前之等待。小數毫秒向上取整。未給或非預期之輸入(非有效正數、超過2147483647、非數字、讀取拋錯)視為未給，不限時，流程與未支援前相同。給了此選項之呼叫所用之常駐瀏覽器，其WHtml2png.close()與閒置自動關閉亦限時並可強制結束(其處置結果不回傳亦不通知)

輸入觀察回調函數，格式為(e)=>{}，e為凍結之事件物件{ type, ... }，於內部事件發生當下同步呼叫(供測試與診斷以事件而非等待時間同步)，其拋錯與回傳值皆忽略，預設null；type為'attempt'(開始一次嘗試，含attempt、timeout)、'step'(進入步驟，含attempt、step)、'page-settled'(載入後等待頁面完成之結果，含attempt、result為'settled'已靜止、'no-load'限時內未load或頁面已關閉、'busy'限時內未能靜止、'no-timer'頁面計時器未回應或'error'頁面內等待反覆失敗；後四者不視為失敗，續往下檢查與截圖)、'timeout'(該次嘗試逾時，含attempt、step、timeout)、'page-close-start'(逾時後開始限時關閉頁面，含attempt)、'page-close'(逾時後關閉頁面之結果，含attempt、closed)、'browser-close-start'(開始限時關閉瀏覽器)、'browser-close'(限時關閉瀏覽器之結果，含closed)、'browser-kill'(強制結束之處置，含result為'killed'、'gone'、'no-pid'、'unverified'、'failed'或'unconfirmed'，及pid)、'cancelled'(已逾時之嘗試於其進行中之步驟成功返回後被放棄，含attempt、step；以錯誤返回者不通知；此事件與逾時之嘗試其後的'step'可能在呼叫已reject之後才通知)、'retry'(失敗後即將等待再試，含attempt、wait)；'browser-kill'的result為'gone'時代表與瀏覽器之連線已斷而未結束行程，單次出圖成功後釋放瀏覽器失敗(如pid不明)不影響回傳圖片，僅經此事件可見
